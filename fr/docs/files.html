Fichiers et stockage

Enregistrer, ouvrir, l’enregistrement automatique, les noms de fichiers et le stockage du navigateur.

Les fichiers de diagramme

Violet enregistre chaque diagramme dans un fichier HTML lisible. Son extension indique le type de diagramme :

DiagrammeExtension
Classes.class.violet.html
Séquence.seq.violet.html
Activité.activity.violet.html
États.state.violet.html
Objets.object.violet.html
Cas d’utilisation.ucase.violet.html

Enregistrer et ouvrir

  • Fichier › Enregistrer (Ctrl+S) et Enregistrer sous ;
  • Fichier › Ouvrir (Ctrl+O) et Fichiers récents ;
  • Fichier › Fermer (Ctrl+W) ; Document › Tout fermer.

Les nouveaux diagrammes sont enregistrés automatiquement sous un nom provisoire, deux secondes après votre dernière modification : vous ne perdez jamais votre travail. Cliquez sur le nom du diagramme dans la barre du haut pour le renommer.

Fichiers dans le navigateur

Dans la version en ligne, les diagrammes sont conservés dans le stockage du navigateur :

Pour…Utilisez
Ouvrir un diagramme conservé dans le navigateurFichier › Ouvrir
Charger un diagramme depuis votre ordinateurFichier › Importer depuis › Fichier local
Télécharger le diagramme courantFichier › Exporter vers › Fichier diagramme
Supprimer un diagramme du navigateurFichier › Ouvrir, puis l’icône corbeille

Dans la fenêtre Ouvrir, les diagrammes sont classés du plus récemment modifié au plus ancien. Un diagramme ouvert ne peut pas être supprimé : fermez-le d’abord.

À savoir Effacer les données du navigateur efface aussi vos diagrammes. Exportez ceux que vous voulez garder.
