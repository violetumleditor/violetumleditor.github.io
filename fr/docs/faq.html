Documentation / Aide

FAQ

Questions fréquentes.

Violet est-il gratuit ?

Oui. Violet est libre et gratuit, publié sous licence GNU GPL.

Où sont stockés mes diagrammes en ligne ?

Dans le stockage de votre navigateur, sur votre propre appareil. Ils ne sont pas envoyés à un serveur. Voir Fichiers dans le navigateur.

Quelle version de Java faut-il ?

Java 17 ou plus pour la version de bureau. La version en ligne ne demande aucune installation de Java.

Dans quelles langues l’interface existe-t-elle ?

Anglais, français et allemand, selon la langue de votre système.

Puis-je ouvrir des diagrammes faits avec d’anciennes versions ?

En général, oui. Si un fichier est signalé comme incompatible, continuez à le modifier avec la version de Violet qui l’a créé.

Comment signaler un bug ou contribuer ?

Ouvrez un ticket ou une pull request sur GitHub.
