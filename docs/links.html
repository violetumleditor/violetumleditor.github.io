Linking elements

Draw UML relationships between elements.

With a relationship tool

Pick a relationship in the panel (for example Inherits from), then drag from one element to another. Violet draws the link with right angles and returns to the Select tool.

With the link handle

Select an element and drag its round violet arrow button onto another element — or tap it, then tap the other element, which is easier on a touch screen. Only the kinds of links the diagram allows between these two elements are offered: if there is just one, it is added at once; otherwise, pick one in the small row of icons that appears. A right click or Escape cancels.

Text on a link

Select a link and type: the text goes in the middle of the link. The link’s properties also offer a start label, an end label and line styles.
