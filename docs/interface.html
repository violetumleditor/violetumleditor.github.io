Documentation / Using Violet

The interface

The top bar, the tool panel and the canvas.

The top bar

The violet bar holds the menus (File, Edit, View, Document, Help), the name of the current diagram and quick buttons:

  • Undo and redo;
  • Cut, copy, paste and delete;
  • Zoom out, the zoom level, zoom in;
  • The light / dark theme switch;
  • Full screen.

Click the diagram name to rename it. When the diagram has unsaved changes, its name is preceded by Unsaved. On a narrow window, the menus fold into a single menu button.

The tool panel

  • Search a tool — type a few letters to filter the tools.
  • Common tools — Select, Note, Text, Image and Area (a grouping area), and generic links: Line, Arrow, Double, Dotted and Bent.
  • The diagram card — the elements and UML relationships of the current diagram type.
  • Style — colors and line thickness for the selection (see Colors and thickness).

The small tab on the edge of the panel hides it, to give the whole width to the canvas.

The canvas

The canvas is where you draw. Hold Ctrl and use the mouse wheel to zoom; hold Ctrl and drag an empty spot to move the view (or double-click an empty spot and drag without releasing).

Several diagrams at once

You can keep several diagrams open. The Document menu lists them, lets you switch between them and Close all.
